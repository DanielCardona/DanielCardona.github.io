ATS-friendly resume: the basics

Updated: 2026-10-20 · 5 min read

Many companies use an ATS (Applicant Tracking System) to receive, sort and search resumes. An ATS extracts the text from your file and organizes it into fields. If it cannot read your file well, your information may end up incomplete or misfiled. Here are the basics to avoid that.

What an ATS does (and does not do)

An ATS stores applications, lets recruiters search by keyword and helps the hiring team stay organized. In general it does not "reject" anyone on its own over a design detail, but a resume the system cannot read is harder to find and to evaluate. People will read it later too, so your resume has to work for both.

A format that reads well

  • Real text: use a PDF with selectable text (not a scanned image or screenshot). If you can select and copy the text, the system can too.
  • Simple structure: one column, clear headings and a logical order. Complex tables, text boxes and multiple columns can scramble the reading order.
  • Standard fonts at a readable size (10-12 pt).
  • Icons and graphics: use them sparingly. Skill bars or stars are not read as text; state the level in words ("Spanish: B2").
  • Key information in the body, not in headers or footers, which some systems ignore.

Standard section headings

Use recognizable names: "Work experience", "Education", "Skills", "Languages". Creative headings ("My journey") make classification harder.

Keywords without tricks

  1. Read the posting and note the skills, tools and qualifications it asks for.
  2. Include those terms naturally wherever they are true for you: in your summary, achievements and skills list.
  3. Write both the full name and the acronym where relevant ("Project Management Office (PMO)").

Avoid keyword stuffing or hidden text: it does not work well and the people reviewing your resume will notice.

Dates and contact details

  • Use a consistent date format (for example, "03/2022 - 08/2024").
  • Email and phone in plain text; make links visible, not only behind an icon.

File name and type

Always follow the job posting's instructions. If none are given, a PDF with selectable text is usually the safest option and preserves the layout. Name the file clearly: First-Last-CV.pdf.

How to check it

  • Open the PDF, try selecting and copying the text, paste it into a plain text editor and check that the order makes sense.
  • Make sure no accents, bullets or contact details were lost.
